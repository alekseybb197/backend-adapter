# Реализация ADR-$0

## 1. Проверка входа — до любых изменений

1. Найди файл `docs/adr/$0-*.md`. Нет файла — остановись и сообщи.
2. Прочитай строку `| Статус | …`. Первое слово обязано быть `Принято`.
   - `Предложено` — не реализовывать. Предложи заполнить раздел «Оценка
     реализации» и остановись.
   - `Действует` / `Заменено` / `Отклонено` — остановись и сообщи.
3. Прочитай ADR целиком и ADR из его поля «Связано». Каталог целиком не читай;
   `docs/adr/archive/` не читай.
4. Если ADR описывает несколько этапов («слои», «шаги», «вариант B, затем A»)
   и в задаче не сказано, какой реализовать, — спроси и остановись.

## 2. Ветка

`git switch -c adr/$0-<краткое-имя>` от актуальной основной ветки. Рабочее
дерево должно быть чистым; иначе — остановись.

## 3. Реализация

- Объём — строго раздел «Решение». Не расширять, не «улучшать попутно».
- Найденное по ходу расхождение ADR с кодом, или место, где решение
  неосуществимо как написано, — не исправлять молча и не выбирать вариант
  самостоятельно: остановись и опиши расхождение.
- Соблюдай действующие ADR подсистемы (они подгружаются правилами
  `.claude/rules/adr-*.md`) и инвариант DAG из `CLAUDE.md`.
- Новые env-переменные — по списку из правила `adr-config.md`.

## 4. Тесты

- На каждое поведение из разделов «Решение» и «Проверка» — тест, включая
  отрицательные случаи (неверный ввод, граничные значения, отказ).
- Для исправления дефекта — сначала тест, падающий на текущем коде.

## 5. Обязательные проверки (все четыре зелёные)

```bash
ruff check backend_adapter/ backend-adapter.py
ruff format --check backend_adapter/ backend-adapter.py
mypy --strict --ignore-missing-imports backend_adapter/ backend-adapter.py
pytest
```

## 6. Документация

- Документация, затронутая изменением (`docs/*.md`, `README.md`,
  `CLAUDE.md`) — в том же коммите.
- `changelog.md` — запись в текущей WIP-версии: Цель / Решение / Следствия,
  со ссылкой «ADR-$0».
- ADR-$0: строка статуса → `| Статус | Действует (<версия>, <коммит>) …`;
  раздел «Оценка реализации», если был, — оставить.
- `docs/adr/README.md` — перенести ADR-$0 из таблицы «Предложения» в каталог
  действующих решений, обновить строку «Находки сверки», если ADR её закрывает.

## 7. Итог

Коммит(ы) в ветке `adr/$0-…`. В отчёте: что сделано, какие тесты добавлены,
результат четырёх проверок, найденные расхождения. Не пушить и не мерджить
без указания пользователя.
