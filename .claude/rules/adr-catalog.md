# Правила работы с каталогом ADR

- Файл `docs/adr/NNN-краткое-имя.md`, NNN — следующий свободный номер. Новый ADR —
  по `docs/adr/TEMPLATE.md`.
- Статус — первое слово строки `| Статус | …`, одно из:
  `Предложено → Принято → Действует`; `Заменено (ADR-…)`; `Отклонено`.
- Агент создаёт только «Предложено». «Принято» ставит только автор проекта.
  После реализации агент переводит «Принято» → «Действует» со ссылкой на коммит.
- Решение со статусом «Действует» не переписывать: изменение — новый ADR, у
  старого — «Заменено (ADR-…)».
- Разделы «Ответ автора» не редактировать — это первоисточник.
- `docs/adr/archive/` — исторический первоисточник: не редактировать, в работе не
  читать.
- После изменения статуса или добавления ADR — обновить таблицы в
  `docs/adr/README.md`. Формат проверяет `tests/test_adr_catalog.py`.
