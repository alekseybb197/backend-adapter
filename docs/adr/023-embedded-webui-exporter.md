# ADR-023: Встроенный WEBUI в процессе адаптера; отдельный слушатель Prometheus

| Поле | Значение |
|---|---|
| Статус | Принято (v0.7.0); «всегда включён» — v0.8.6; health и экспортёр — v0.8.5 |
| Тип решения | deliberate (записано) |
| Уверенность | high |
| Источник рационала | журнал ADR 2026-09-02, 2026-09-04, 2026-09-07, 2026-09-08 |

## Контекст

Сырые `.parts`-дампы длинных сессий невозможно читать. Для просмотра
существовали отдельные скрипты в `tmp/`, жившие вне пакета.

## Решение

- WEBUI — **поток-демон внутри процесса адаптера**, не дочерний процесс и не
  отдельный сервис. Собственное микро-ядро `webserver.py`: реестр эндпойнтов
  по префиксу (`@webserver.register`), самый длинный префикс побеждает.
- Страницы: `/` (статус, бэкенды, «Models in use»), `/sessions`, `/session`
  (дерево артефактов), `/config` (runtime-пул), `/errors/<имя>`.
- **Флага отключения нет** (v0.8.6; было `ADAPTER_WEBUI_ENABLE`): WEBUI —
  единственный способ увидеть состояние, «zero-config: состояние видно сразу».
- Изменяющие действия — POST + **303 See Other** (PRG): обновление страницы не
  повторяет действие.
- Live-обновление — JS-опрос лёгких JSON-эндпойнтов (`/api/*/snapshot`),
  без WebSocket.
- Health (`/healthz`, `/health`, `/live`, `/ready`) — на слушателе WEBUI.
- **Prometheus-экспортёр — отдельный слушатель** (`ADAPTER_EXPORTER_PORT`,
  9100), stdlib-only, text exposition 0.0.4. Не эндпойнт WEBUI: повторный
  `serve()` перезаписал бы реестр и открыл бы весь WEBUI на порту метрик.
  Ошибка bind не роняет адаптер.

## Рассмотренные альтернативы

- Отдельный процесс-просмотрщик (скрипты в `tmp/`). Отвергнут: вне пакета,
  отдельный запуск.
- WEBUI выключен по умолчанию (до v0.7.2). Отвергнуто.
- `/metrics` на порту WEBUI. Отвергнуто (см. выше).

## Следствия

- Адаптер — одновременно прокси и веб-приложение со своим HTML/JS в Python-
  строках. Код WEBUI и дерева артефактов (`webui_*`, `webserver`,
  `session_viewer`, `artifact_tree*`, `artifact_refresh` — ~6000 строк)
  **больше** ядра прокси (`server`, `convert`, `streaming`, `routing` —
  ~4600 строк).
- WEBUI делит процесс и GIL с прокси: тяжёлая отрисовка дерева вынесена в фон
  (ADR-027).
- WEBUI не имеет аутентификации; защита — только адрес привязки (ADR-024).
- Экспортёр включён по умолчанию (`ADAPTER_EXPORTER_ENABLE=1`) на порту 9100,
  стандартном для `node_exporter`: на хосте с ним экспортёр адаптера молча не
  поднимется (только строка `[EXPORTER] Failed to bind`).

## Доказательства

- `backend_adapter/webserver.py` (`register`, `serve`), `webui_*.py`,
  `session_viewer.py`, `prometheus_exporter.py` (`serve_exporter`).
- `backend_adapter/config.py`: `ADAPTER_WEBUI_PORT` (8765),
  `ADAPTER_EXPORTER_ENABLE` (`1`).
- `1d33d50`, `e98c0fe`, `2bedabc`, `56fc616`, `5d529d4`.
