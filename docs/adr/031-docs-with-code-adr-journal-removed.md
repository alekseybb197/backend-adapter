# ADR-031: Документация вместе с кодом; журнал ADR упразднён в пользу changelog

| Поле | Значение |
|---|---|
| Статус | Действует (`fdbead0`, 2026-09-09); **предлагается к пересмотру** этим каталогом |
| Тип решения | deliberate (записано) |
| Уверенность | high |
| Источник рационала | сообщения коммитов `d72f1cb`, `fdbead0`; changelog v0.9.11; `CLAUDE.md` «Принципы» |

## Контекст

С 2026-09-03 в `CLAUDE.md` вёлся «Журнал решений (ADR)» — 25 записей к
2026-09-09, ~940 строк. Правило журнала: только архитектурные и существенные
решения, каждая запись сопровождается блоком в `changelog.md` (`d72f1cb`).
На практике записи группировались по релизам и включали UI-мелочи (favicon,
иконки, колонки), дублируя changelog.

Записанный мотив удаления — один: «полная история решений остаётся в
changelog.md». **Гипотеза (не записано):** `CLAUDE.md` — контекст ИИ-агента
разработки, и ~940 строк журнала расходовали его контекстное окно; в том же
коммите `CLAUDE.md` переписан под стандартную шапку `/init`.

## Решение

- Раздел «Журнал решений (ADR)» удалён из `CLAUDE.md` вместе с требованием
  его вести: «полная история решений остаётся в changelog.md» (`fdbead0`).
- Принцип «документация обновляется вместе с кодом, а не после».
- Changelog — формат «Цель / Решение / Следствия» на ветку.
- v0.9.11: changelog **свёрнут** — всё до v0.9.1 сжато в две сводки (4032 →
  1526 строк); «детали — в git-истории».
- `__comment__` — константа назначения, а не перечень фич (v0.9.9).

## Следствия (наблюдаемые)

- Рационал решений v0.9.1–v1.0.0 записан только в changelog, где он смешан с
  перечнем изменений; рационал v0.3–v0.9.0 после сворачивания доступен только
  через `git show`.
- **Висячие ссылки:** код и тесты ссылаются на «ADR … в CLAUDE.md»
  (`shutdown.py`, `backend-adapter.py`, `tests/test_shutdown.py`,
  `tests/test_manual_check.py`), документация — на «ADR 2026-09-01»
  (`docs/architecture.md` §2), которой с таким содержанием не существовало.
- Предмет решений и их альтернативы перестали быть отдельной сущностью: чтобы
  ответить «почему так», нужна реконструкция (этот каталог).

## Предложение (на решение автора)

Вести ADR в `docs/adr/` отдельными файлами, **вне** `CLAUDE.md`: это
сохраняет исходный мотив удаления (не раздувать контекст агента) и
возвращает отдельную сущность «решение». В `CLAUDE.md` — одна строка-ссылка.
Критерий записи — тот же, что в `d72f1cb`.

## Доказательства

- `git show 967629a:CLAUDE.md` — последняя версия с журналом; сохранена в
  `docs/adr/archive/2026-09-09-claude-md-adr-journal.md`.
- `fdbead0` — удаление (−948 строк `CLAUDE.md`).
- `e30c99f` — сворачивание changelog.
