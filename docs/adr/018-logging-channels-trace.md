# ADR-018: Каналы логов — консоль всегда с обрезкой, файл полный за одним флагом; JSONL-трейс с причинностью

| Поле | Значение |
|---|---|
| Статус | Принято; текущая форма — v0.9.10 (один флаг), v0.9.13 (`ADAPTER_LOG_TRIM`) |
| Тип решения | deliberate (записано) |
| Уверенность | high |
| Источник рационала | changelog v0.3.0; журнал ADR 2026-09-03, 2026-09-04, 2026-09-08 (×2); changelog v0.9.8, v0.9.10, v0.9.13 |

## Контекст

Адаптер нужен прежде всего для отладки поведения агента на нестандартной
модели: что агент отправил, что модель ответила, почему выбрала инструмент.
Объём данных огромен (полные промпты, reasoning, результаты инструментов),
а консоль должна оставаться читаемой.

## Решение (текущее)

| Канал | Когда пишется | Полнота | Назначение |
|---|---|---|---|
| Консоль (`_d`/`_dr`) | всегда | обрезка `ADAPTER_LOG_TRIM` (1000; `0` — без обрезки) | наблюдение в реальном времени |
| `session-*.log` | `ADAPTER_DEBUG_ENABLE=1` **и** запрос несёт `session_id` | полные строки | ручной разбор сессии |
| `session-*.jsonl` (trace) | то же | полные события | аналитика |
| `*.parts` (`.json`+`.yaml` пары) | то же | полные части протокола | просмотр в WEBUI, дерево артефактов |
| `.err` | безусловно | полные | инциденты (ADR-019) |

- Один флаг управляет всем файловым (v0.9.10).
- Каждая строка консоли и файла начинается с `[req_id]` (v0.3.0).
- **Trace — главный аналитический канал** (v0.3.0): reasoning пишется
  целиком («единственное место, где видно, ПОЧЕМУ модель выбрала
  инструмент»), аргументы `tool_call` — целиком; причинная связь
  `tool_use_id` → `parent_req_id` через сессионный индекс (надёжнее порядка по
  времени при параллельных ветках); `request_kind` отделяет побочные вызовы
  харнесса (генерация заголовка) от основного цикла.
- Запрос без `session_id` файлов не пишет вообще (v0.9.8).

## Следствия

- Консоль безусловна: при высокой нагрузке она становится узким местом и
  источником больших объёмов в journald/docker-логах. Регулируется только
  длиной обрезки.
- Файловые данные содержат полный контекст агента (код, файлы, секреты из
  вывода инструментов) — отсюда маскирование (ADR-020) и привязка к
  localhost (ADR-024).
- Файлы не удаляются никогда: FIFO в `session_log.py` вытесняет только
  **открытые дескрипторы**, а не файлы. Ограничения объёма каталога `log/`
  нет.

## Доказательства

- `backend_adapter/logger.py` (`_d`, `_dr`), `tracer.py`, `session_log.py`
  (`logging_enabled`, `write_debug_json`).

  `ADAPTER_LOG_TRIM` (`1000`).
- `93c4d15`, `93a303c` (реформа v0.8.6), `de59582` (один флаг).
