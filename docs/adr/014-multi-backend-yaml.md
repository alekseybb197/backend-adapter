# ADR-014: Несколько бэкендов в YAML; токены — только по имени env-переменной

| Поле | Значение |
|---|---|
| Статус | Действует (v0.5.0); legacy-режим удалён в v0.7.2; горячее перечитывание — v0.8.5 |
| Тип решения | deliberate (записано) |
| Уверенность | high |
| Источник рационала | changelog v0.5.0 (восстановлен из `becdabd9:changelog.md`); журнал ADR 2026-09-03 и 2026-09-07 |

## Контекст

Один агент может работать с моделями разных провайдеров (локальный сервер,
корпоративный шлюз). Изначально бэкенд задавался парой
`ADAPTER_BACKEND_BASE`/`ADAPTER_BACKEND_KEY`.

## Решение

- `ADAPTER_BACKEND_CONFIG` — путь к YAML: список `{name, base, key}`.
- **`key` — имя env-переменной**, а не сам токен: секрет не попадает в файл
  конфигурации и раскрывается при старте.
- Маршрутизация модели: явный префикс `<backend>.model` → этот бэкенд
  (префикс срезается); иначе — поиск по общему списку моделей; иначе —
  первый бэкенд в файле.
- Одинаковые `id` моделей на разных бэкендах получают префикс
  `<backend>.` автоматически.
- Legacy-пара переменных удалена (v0.7.2): один способ конфигурации; пустой
  `ADAPTER_BACKEND_CONFIG` → `[FATAL]` с подсказкой.
- Кнопка «Перепроверить» перечитывает YAML на лету (v0.8.5); битый файл —
  `[WARN]`, прежние бэкенды остаются.
- Модельный маппинг `ADAPTER_MODELS_MAPPING` — отдельный слой поверх, без
  учёта префиксов (для субагентов [CC]).

## Рассмотренные альтернативы

- Сохранить оба способа (env-пара и YAML). Отвергнуто: двойные ветки кода и
  документации.
- Токен прямо в YAML. Не выбран — ключ всегда ссылка на env (мотив не
  записан, но следует из принципа маскирования секретов, ADR-020).

## Следствия

- Минимальная настройка — два шага (YAML + env токена), а не один.
- Фолбэк «первый бэкенд» может молча отправить запрос с опечаткой в имени
  модели не туда, если `ADAPTER_STRICT_MODELS=0` (ADR-015).
- Парсер YAML самописный и понимает подмножество формата. Запись, где первым
  ключом идёт не `name`, молча склеивается с предыдущей — токен одного
  бэкенда может уйти на адрес другого, а `--check` такой файл одобряет
  (подтверждено, подробности и пример — ADR-005).
